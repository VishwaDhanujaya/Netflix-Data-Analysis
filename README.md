# Netflix Data Analysis

## Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset.

The goal is to identify trends in content distribution, production countries, and genre popularity.

## Dataset
Source: Kaggle Netflix Dataset

## Tools Used
Python
pandas
numpy
matplotlib
seaborn
Jupyter Notebook

## Key Insights
- Netflix hosts more Movies than TV Shows
- Content growth increased significantly after 2015
- United States produces the most content
- Drama and International Movies are dominant genres
